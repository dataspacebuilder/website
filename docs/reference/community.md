### Contributing

EDC follows standard Eclipse Foundation governance:
- Contributions via pull requests on GitHub
- [Eclipse Contributor Agreement (ECA)](https://www.eclipse.org/legal/ECA.php) required
- IP review for significant contributions
- Community consensus for architectural changes

Start by exploring the [EDC Discussions](https://github.com/eclipse-edc/Connector/discussions) and reviewing open issues on the repositories you're interested in.

## Industry Dataspaces

Active large-scale dataspace initiatives built on EDC and related technologies:

| Initiative | Sector | Description | Link |
|---|---|---|---|
| **Catena-X** / Eclipse Tractus-X | Automotive | Largest EDC-based dataspace; hundreds of organizations | [catenax-ev.github.io](https://catenax-ev.github.io/) / [eclipse-tractusx.github.io](https://eclipse-tractusx.github.io/) |
